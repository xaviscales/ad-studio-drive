Privacy policy

Last updated: 16 November 2026

Who uses it

Ad Studio Drive is a private tool used only by its owner. It has no other users.

What it accesses

With the owner's permission, it uses the Google Drive API on the owner's own Google account to find their delivery folders, create folders and upload or replace their own video files.

It does not share files, change sharing settings or delete anything.

What it keeps

The Google sign-in token is stored only in the owner's private cloud account, so the uploads can run.

No Google data is sold, shared with anyone else or used for advertising.

Google API Services User Data Policy

Ad Studio Drive's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove access at any time at myaccount.google.com/permissions.
